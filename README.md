# CarDeck releases

Signed release builds of CarDeck (`net.webotion.cardeck.auto`), an Android Auto media app.
The app's built-in updater reads the latest release here (`update.json` + `CarDeck.apk`) and
offers only major and minor versions.

Signing certificate SHA-256:
`01756524977b652de55b8e9f3e06b13c428cca63a6d63131d0eca7c2eba00a6e`

GPL-3.0 (see LICENSE). The corresponding source code of each release is available on request.
